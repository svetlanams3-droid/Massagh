# 🎯 Быстрый старт - Админ-панель

## 🔐 Как войти в админ-панель

1. **Прокрутите страницу вниз** до футера
2. **Найдите иконку шестеренки** ⚙️ (справа от текста копирайта)
3. **Кликните на неё** - откроется модальное окно
4. **Введите пароль**: `admin123`
5. **Нажмите "Login"**

## 📝 Что можно редактировать

### 🖼️ Изображения
- Фоновое изображение Hero секции
- Изображения всех 4 услуг (Deep Tissue, Swedish, Sports, Aromatherapy)
- Изображение About секции
- Аватары клиентов в отзывах

### 📝 Тексты
- Все заголовки и подзаголовки
- Описания услуг
- Цены и продолжительность
- Тексты отзывов
- Контактная информация
- URL для Calendly

## 💡 Как редактировать

1. **Выберите вкладку** в левой панели (Hero, Services, About, Reviews, Booking, Footer)
2. **Измените нужные поля** в форме
3. **Нажмите кнопку "Save"** в верхней панели
4. **Изменения применятся** мгновенно на сайте

## 🔄 Сброс настроек

Если нужно вернуть все настройки по умолчанию:
1. Войдите в админ-панель
2. Нажмите кнопку **"Reset"** в верхней панели
3. Подтвердите действие

Все изменения будут сброшены к исходным значениям.

## 💾 Сохранение данных

- Все изменения **автоматически сохраняются** в LocalStorage браузера
- Данные **не теряются** при перезагрузке страницы
- Структура данных готова для подключения к **PocketBase** или **Firebase**

## 🎨 Примеры использования

### Изменить фоновое изображение Hero:
1. Перейдите во вкладку "Hero"
2. Найдите поле "Background Image URL"
3. Вставьте новый URL изображения (например, с Unsplash)
4. Нажмите "Save"

### Изменить описание услуги:
1. Перейдите во вкладку "Services"
2. Найдите нужную услугу
3. Измените текст в поле "Description"
4. Нажмите "Save"

### Обновить Calendly:
1. Перейдите во вкладку "Booking"
2. Вставьте новый URL в поле "Calendly URL"
3. Нажмите "Save"

## 🔒 Безопасность

- Пароль хранится в коде (`src/App.tsx`)
- Для продакшена рекомендуется:
  - Изменить пароль на более сложный
  - Использовать серверную аутентификацию
  - Подключить базу данных вместо LocalStorage
